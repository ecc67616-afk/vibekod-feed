# vibekod-feed

Очередь постов для канала @vibekod_put. Бот-публикатор каждые 15 минут читает `posts.json`
и публикует посты, у которых время `at` уже наступило.

Формат записи:

```json
{"id": "2026-12-01-first", "at": "2026-12-01T10:00:00+03:00", "text": "Текст поста (можно <b>жирный</b>)", "photo": "https://ссылка-на-обложку.jpg"}
```

`photo` необязателен. `id` должен быть уникальным: по нему бот помнит, что пост уже вышел.
